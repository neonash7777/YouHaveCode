# Generated Screenshots

Run `npm run screenshots` from this extension directory to refresh every image. Pass scenario names to refresh a subset, for example `npm run screenshots -- root-menu output-format-menu`. Add `-- --keep-open` to leave the isolated VS Code window open for inspection.

Generated scenarios: root-menu, properties-menu, output-format-menu, custom-tags-menu, tag-search-menu, sidebar-overview, unicode-table-sidebar, pretty-print-settings-sidebar, compatibility-warning-menu.
