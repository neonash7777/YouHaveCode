## Unicode Character Database And Emoji Data

The generated files `data/unicode_compact.csv`, `data/unicode_property_aliases.csv`, and `data/emoji_rgi.tsv` contain data derived from the Unicode Character Database and Unicode Emoji 17.0 data files.

The file `data/compatibility_profiles.json` includes YouHaveCode compatibility metadata. Its current macOS font coverage profile is generated from installed system font cmap tables on the maintainer's reference machine. The profile stores only compact code-point ranges and source notes; it does not include Apple, Microsoft, Google, Canonical, Ubuntu, or other platform font files. Provisional current profiles for iOS, Android AOSP, Windows, and Ubuntu are clearly marked in that JSON until pinned platform cmap scans are available.
